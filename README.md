# 📱 TMA Builder (Telegram Mini App Constructor)

Платформа-конструктор для создания и управления **Telegram Mini Apps** для ресторанов, кафе, магазинов и сферы услуг. Позволяет заведение за считанные минуты запустить полноценное витринное приложение с приемом заказов и автоматическими уведомлениями в Telegram.

---

## ✨ Основные возможности

### 🏪 Мульти-витрины и Управление Заведениями
* **Создание нескольких заведений** под одной учетной записью с индивидуальными ссылками вида `/shop/:slug`.
* **Управление профилем:** Название, описание, адрес, контактный телефон, график работы.
* **Статус работы:** Оперативное переключение состояния приема заказов (**Открыто** / **Временно закрыто**).

### 🍕 Меню, Услуги и Категории
* **Каталог товаров:** Гибкая настройка наименований, описания, цен, изображений и категорий.
* **Фильтрация и поиск:** Мгновенный поиск по меню и переключение категорий для покупателей.
* **Лимиты:** Наглядный контроль количества услуг в рамках выбранного заведения.

### 🛒 Корзина и Оформление Заказов
* **Удобный заказ:** Выбор формата обслуживания:
  * 🛍 **Навынос**
  * 🍽 **В заведении** (с указанием номера столика)
  * 🚚 **Доставка** (с указанием времени)
* **История заказов:** Вкладка «Мои заказы» с отслеживанием актуального статуса в реальном времени.

### 🤖 Интеграция с Telegram
* **Уведомления администратору:** Мгновенная отправка детальных карточек новых заказов в Telegram-чат или канал.
* **Мастер настройки:** Пошаговая инструкция внутри панели управления по созданию бота через `@BotFather` и получению `Chat ID`.

### 📊 Аналитика и Админ-панель
* **Панель заказов:** Смена статусов (*В обработке*, *Готовится*, *Готов*, *Завершен*, *Отменен*).
* **Метрики бизнеса:** Подсчет общей выручки, среднего чека, количества заказов и наглядная аналитика по дням/неделям.

## 🛠 Технологический стек

* **Frontend:** React 18, Vite, Tailwind CSS, Lucide React, React Router DOM
* **Backend:** Node.js, Express, TypeScript, esbuild
* **Database & ORM:** PostgreSQL, Prisma ORM
* **Authentication:** JWT, bcryptjs

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/blesswrld/tma-builder.git
cd tma-builder
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге и укажите необходимые переменные:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/tma_builder?schema=public"
JWT_SECRET="your-super-secret-jwt-key"
PORT=3000
NODE_ENV=development
```

### 4. Подготовка базы данных
Выполните накатывание схемы Prisma в вашу БД:

```bash
npx prisma db push
```

### 5. Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

## 📦 Сборка и Запуск в Продакшн

